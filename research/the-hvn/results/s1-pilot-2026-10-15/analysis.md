# S1 Brand Perception Pilot: Analytical Report

**Run:** 15 October 2026 · MiroFish Reddit mode · `claude-haiku-5-5` only · 10 agents · 8 rounds (max) · graph memory updates off
**Total API cost:** **$0.084** (cap $1.00) · 53 requests (1 free connectivity check) · 452,459 input / 77,574 output tokens
**Raw data:** `raw/` (simulation DB and JSON export, OASIS logs, profiles, config, proxy ledger, report-agent log) · metrics in `run-metrics.json`

> **Labels.** **[SIMULATED]** = something an LLM agent said in this run. It is a hypothesis about how such a person *might* react, **not customer evidence**. **[VERIFIED]** = established in the Phase 0 research (`../../dossier.md`, `../../website-audit.md`), mostly from the live site on 15 Oct 2026.

---

## 1. Bottom line

1. **The pipeline and safeguards worked; the simulation produced very little discussion.** Only **3 agent actions** happened in 8 rounds (plus 4 seeded opening posts and 1 like). The simulated clock started at **00:00**, so the 8 rounds covered 00:00–08:00, outside most agents' active hours. That is a configuration problem, not a finding about The HVN.
2. **The few simulated reactions all point the same way: verification beats luxury.** Agents asked for things they could check (test lists, credit terms, regulator scope, practitioner registration, review counts). No agent discussed ambience, exclusivity or the Hydrobed. This is a thin signal from about 9 messages and must not be generalised.
3. **The MiroFish auto-report is unreliable** (§5) and should not be quoted. Its interviews failed and it confuses entities from the knowledge graph.
4. **Spend was well within the cap.** Simulation steps cost only $0.004 because so few agents acted. The cost of a fully active run is still unknown (§6).

## 4. Implications [HYPOTHESIS, to validate with real clients]
1. **Make verification easy, not just luxury visible.** A visible CQC link and status line, clinician registration numbers, review score, and written terms address S3–S4 and match audit W7.
2. **Publish decision detail for testing products.** Analyte lists, the lab used, what the £150 follow-up includes, and exactly what the £100 credit applies to (S2, audit W8).
3. **Aesthetics pages:** state whether the £175 consultation is redeemable, and show who performs treatments (S5).
4. **Drop or substantiate the superlative.** "London's leading" earned no credibility in simulation (S1) and carries substantiation risk (audit W4).

None of these depends on the simulation alone; each is already supported or prompted by verified website evidence.

## 5. Audit of the MiroFish auto-report (`mirofish-report.md`)

Where the auto-report is consistent with the raw logs and evidence (trust depends on verifiable credentials, regulation and pricing; the superlative is weak), that agreement is already captured in §3 from the primary data.

## 7. Safeguard verification record
- Real API key held **only** by the budget proxy (injected per request). The backend ran with a placeholder, verified from its process environment (booleans only). Direct calls to Anthropic with the backend's credentials returned **HTTP 401**.
- Proxy-to-Anthropic connectivity was verified with a **free** `count_tokens` call before any paid call. Routing was verified on the first paid call (ontology, $0.003).
- Every request passed through the proxy: 53/53 Haiku, 53 × HTTP 200, 0 refused, 0 upstream errors, so no retries were triggered.
- Worst-case cost reservation was enforced against the $1 cap; the guard thresholds ($0.70 stop, $0.80 report skip) were never reached.
- Graph memory updates were disabled. The Zep graph `mirofish_e60ebfc8501b4e0c` **still exists**; delete it with `cd research/the-hvn/pilot && python3 run_pilot.py --stage cleanup --confirm-zep` (needs the backend running) if it should not persist.
